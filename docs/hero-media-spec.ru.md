# Спецификация медиа для Hero

## Назначение

Документ задает требования к изображениям и видео для блока Hero на главной странице.
Подготовлен как готовый материал для передачи дизайнеру.

## Ограничения верстки Hero

- Максимальная ширина контейнера: `1280px`
- Скругление Hero: `24px`
- Режим отображения медиа: `object-cover` (изображение/видео может подрезаться по краям)
- Текстовый контент расположен слева
- На десктопе справа есть декоративная панель, поэтому не размещайте там критичные детали

## Режимы высоты Hero (3 типа)

### 1) `normal`

- Mobile: высота `384px`
- Tablet (`md`): высота `480px`
- Desktop (`lg`): высота `544px`

### 2) `tall`

- Mobile: высота `448px`
- Tablet (`md`): высота `560px`
- Desktop (`lg`): высота `640px`

### 3) `wow`

- Mobile: высота `512px`
- Tablet (`md`): высота `640px`
- Desktop (`lg`): высота `736px`

## Требования к изображениям (слайды Hero)

### Основной исходник

- Master-размер: `2560 x 1440` (16:9)
- Формат: `JPG` или `WebP`
- Рекомендуемое качество: `80-90`

### Дополнительный исходник для tall/wow

- Опционально: `2160 x 1620` (4:3)
- Использовать для сцен, где важно снизить риск подрезки сверху/снизу в высоких режимах Hero

## Требования к видео (слайды Hero)

- Основной master: `1920 x 1080` (`.mp4`, H.264)
- Частота кадров: `24/25/30`
- Рекомендуемый битрейт: `8-15 Mbps`
- Опционально для премиум-сцен: `2560 x 1440`
- Обязательно подготовить poster-кадр в той же композиции

## Правила композиции (важно)

- Левая часть кадра должна оставаться визуально спокойной для читаемости текста
- Ключевой объект лучше размещать в центре/правой трети
- Все критичные элементы держать в безопасной зоне:
  - около `70%` ширины кадра
  - около `70%` высоты кадра
- Не размещать важные мелкие детали у границ кадра (их может обрезать `object-cover`)

## Чеклист передачи дизайнером

Для каждого слайда Hero подготовить:

- Один image master (`2560 x 1440`)
- Опциональный safe-вариант (`2160 x 1620`), если нужен
- Опциональный video master (`1920 x 1080`, H.264)
- Poster-кадр для видео
- Короткую пометку: где фокус и какие зоны чувствительны к кадрированию
